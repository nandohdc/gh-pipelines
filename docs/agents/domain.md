# Domain Docs

Before exploring, read the root `CONTEXT.md` if present and any relevant ADRs in `docs/adr/`. If either is absent, proceed silently.

This is a single-context repository. `CONTEXT.md` and `docs/adr/` are created lazily when domain terms or architectural decisions need recording.

Use defined glossary terms consistently, and explicitly flag any proposal that contradicts an existing ADR.
